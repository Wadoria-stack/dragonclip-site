Privacy Policy

Back to DragonClip · Last updated: 27 October 2026

Short version

DragonClip runs on its owner's own computer. It has no servers, no user accounts, no analytics and no advertising. It does not sell or share any data. Everything it saves stays on that computer.

1. Data DragonClip receives from TikTok

  • Login tokens (access token and refresh token): these let DragonClip upload videos for the user without logging in every time.
  • Basic profile info (TikTok user ID, display name and avatar): used only to show which account is connected.

DragonClip only asks TikTok for the permissions user.info.basic and video.upload. It cannot read the user's messages, followers, likes or other videos, and it cannot post publicly.

2. Data DragonClip sends to TikTok

Only the video files the user chooses to upload. They arrive in the user's TikTok inbox as drafts.

3. Where data is stored

Login tokens and profile info are saved in a file on the user's own computer. They are never sent anywhere except back to TikTok when DragonClip talks to TikTok.

4. Deleting data and removing access

  • Press "Disconnect" in DragonClip's settings, or delete DragonClip's TikTok folder, to remove the saved data.
  • Remove DragonClip's access in the TikTok app under Settings and privacy, Security, Apps and services (names may differ slightly by app version).

5. Children

DragonClip is not meant for children and does not knowingly collect data from them.

6. Changes

This policy may be updated. The date at the top shows the latest version.
